Access Control & Profile Architecture

Welcome to the Role-Based Access Control (RBAC) and Security Guide. As an Administrator, you have full control over what each user can see, create, modify, delete, and manage across the Gretex File Master system.

👥

User Roles & Default Profiles

Overview of built-in roles and their initial capability baselines
👑 Admin
Superuser

Complete, unrestricted control over the entire system. Holds the global wildcard * permission.

Key Capabilities:
  • ✓ All register and file operations (Add/Edit/Delete/Clean)
  • ✓ Manage Users, Reset Passwords & Customize Permissions
  • ✓ Manage Master Dropdowns (Clients, Categories, Bins)
  • ✓ Bulk Updates, Checkouts, CSV Imports & Sticker Printing
  • ✓ Exclusive access to this Admin Guide
💼 Staff
Operational

Designed for regular office staff who actively register files, perform checkouts, print QR stickers, and update locations.

Default Baseline:
  • ✓ View & Search All Registers and Subfiles
  • ✓ Add new registers & add documents into registers
  • ✓ Edit file details & Quick Status/Location update
  • ✓ Multi-select & Bulk Update (Category, Bin, Status)
  • ✓ Check Out & Return Files, Print QR Stickers
  • ✕ Delete Registers or Clean Subfiles (Locked by default)
  • ✕ Settings, Masters, and User Management
👁️ Viewer
Read-Only

Safe, audit-only read access for auditors, department heads, or external viewers who only need to locate files.

Default Baseline:
  • ✓ View Registers, Details, and Files inside
  • ✓ Search and Filter by client, status, old file number
  • ✓ Export search results to CSV
  • ✕ Cannot Add, Edit, or Delete files
  • ✕ Cannot Check Out or Return
  • ✕ Cannot Print Stickers or Bulk Update

How to Configure User Access (Step-by-Step)

Admin workflow to create new users or customize existing accounts
1
Open Users & Access
From the sidebar navigation, expand Settings ⚙️ and click on 👤 Users & Access.
2
Create or Edit User
Click ➕ Add User for new team members, or click ✏️ Edit & Access next to an existing user in the table.
3
Select Preset or Customize
Use the Quick Preset buttons (👑 Full Access, 💼 Standard Staff, 👁️ Read-Only) to auto-fill recommended permissions, or check individual boxes.
4
Save & Instant Sync
Click 💾 Save Changes. Permissions are instantly written as JSON into Google Sheets and take effect on the user's next login or page refresh.

Audit Trail & Soft Delete Policy

How data integrity and complete traceability are maintained
🧹 Soft Deletion Mechanism

When an authorized user deletes a subfile or uses 🧹 Empty Register, the records are not permanently erased from your Google Sheet. Instead, Column L (DELETE) in the Files sheet is flagged as Yes. The application automatically filters these out from display while preserving the raw historical record in the spreadsheet.

🛡️ Immutable Activity Audit Log

Every single state change—including user creation, permission adjustments, register additions, location quick-updates, checkouts, returns, and soft-deletes—is permanently appended to the ActivityLog sheet with the exact Actor, Action, Timestamp, and detailed description.
